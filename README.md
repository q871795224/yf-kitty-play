# 猫猫的小屋 · 试玩发布仓库

[打开游戏](https://q871795224.github.io/yf-kitty-play/)

竖屏手绘风格的放置游戏。摸猫获得暖心点，升级猫窝、迎接新猫、布置小屋。

[打开泡泡小队](https://q871795224.github.io/yf-kitty-play/apps/lane-shooter/)

竖屏手绘射击原型。拖动小猫自动发射泡泡，打破补给箱升级，抵挡小灰鼠、仓鼠和金丝熊。

本仓库只保存运行文件，GitHub Pages 从 main 分支发布。开发工具、原始素材实验和模型工作流在本地维护。游戏存档保存在各自浏览器中。

当前为在线网页版本，尚未接入 PWA 离线缓存及自动更新提示。
